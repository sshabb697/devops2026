# Slide decks

These are **Marp** slides (same as the AZ-104 course). Simple English. Open them in class.

## How to show the slides

1. In Cursor / VS Code, install the extension **Marp for VS Code**.
2. Open a file in this folder (example: `01-Day-Why-Kubernetes.md`).
3. Click **Open Preview to the Side** (or `Ctrl+Shift+V`).
4. Present full screen from the preview.

Export: Marp can export **PDF** or **PPTX** (Command Palette → “Marp: Export”).
