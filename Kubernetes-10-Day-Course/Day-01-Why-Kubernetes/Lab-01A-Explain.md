## Part C — True or false (3 min)

1. Kubernetes builds Docker images.  
2. Kubernetes can restart a crashed app.  
3. You always need Azure to learn Kubernetes.

<details>
<summary>Answers</summary>

2. True.  
3. False — Days 1–7 use a local cluster.
