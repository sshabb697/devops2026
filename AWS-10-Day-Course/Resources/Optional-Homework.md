# Optional Homework (by day)

Short, optional tasks to reinforce each day. 15–30 minutes each.

| Day | Homework |
| --- | -------- |
| 1 | Set a **billing alarm** at $5. Write down your Region and account ID. |
| 2 | Create a second IAM user with **read-only** access and log in as them. |
| 3 | Launch an EC2 instance, install `nginx` instead of Apache, then **stop** it. |
| 4 | Draw your VPC on paper: CIDR, 2 subnets, route tables, gateways. |
| 5 | Turn on **S3 versioning**, upload a file twice, restore the old version. |
| 6 | Connect to your RDS database with a client and run `SELECT 1;`. |
| 7 | Add an **S3 bucket** output to your CloudFormation template. |
| 8 | Make your pipeline fail on purpose (bad build), read the logs, fix it. |
| 9 | Push a second image tag to ECR and roll the ECS service to it. |
| 10 | Rebuild **one** resource from Day 1–9 using only the AWS CLI. |

> After each homework: **delete or stop** what you created. Check the [Teardown Checklist](./Teardown-Checklist.md).
