# Terraform in 5 days
## Simple English. Pictures. Labs.

Write a **recipe**. Azure cooks it.

---

# Who this is for

- New to Terraform is OK
- You can use a terminal
- You have an Azure student / trial account

We **type**. We do not only watch.

---

# What you will make

A **resource group**, then a **storage website**, then a **module**, then **shared state**.

Then we **destroy** so you are not billed.

---

# Every day ≈ 3 hours

Lesson → **Lab** → Lesson → **Lab** → Recap

Azure can be slow. That wait is normal.

---

# The four words

**init** download plugins  
**plan** preview  
**apply** make it real  
**destroy** remove it
